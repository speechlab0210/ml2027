# 機器學習 2027——怎麼指導比你聰明的 AI

**一門不存在的課。** 網站：<https://speechlab0210.github.io/ml2027/>

假設 2027 年是這樣的：AI 寫程式全面超過人類，多數學生直接指揮 AI 做作業，而 AI 連模型都能自己煉。
那一門機器學習課還剩下什麼可以教？

這個 repo 是我對那個問題的完整回答：一份 16 講 + 10 份作業 + 一整套評分制度的課程規劃。

## 這門課在教什麼

當「會寫」不再稀缺，這門課教**人類放手前最後的工作**：出題、引導、驗收、監督——監督到簽名那一刻，叫負責。

- 開學每人發一支 AI 艦隊與課程統一算力額度（40M token + 20 GPU 小時），沒有信用卡也能修完。
- 十份作業裡有九份**預設你會指揮 AI 完成**；只有 HW0「徒手健檢」是關掉 AI 現場考的。
- 排行榜的四級 baseline 全部由官方艦隊擔任——不是你比同學，是你帶的 AI 比我帶的 AI。
- 分數乘上 token 效率係數：燒錢燒贏的不算贏。
- AI 判官不能單獨給你零分：申訴七日、合議庭重評、人類終審。

完整內容見網站或 `content.json`。

## 這個 repo 怎麼跑

```bash
node build.mjs      # content.json + build.mjs 內建的制度資料 → docs/index.html
```

- `content.json` — 16 講 + 10 份作業的結構化內容（唯一內容真相源）
- `build.mjs` — 版面、制度資料表與渲染邏輯
- `docs/index.html` — 產出。整站單檔、零外部依賴、不追蹤、無 cookie、無廣告，可直接丟任何靜態主機
