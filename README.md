**一門不存在的課，正在變成一季影片。** 網站：<https://speechlab0210.github.io/ml2027/>

假設 2027 年是這樣的：AI 寫程式全面超過人類，多數學生直接指揮 AI 做完手上的事，而 AI 連模型都能自己煉。

## 這門課在教什麼

當「會寫」不再稀缺，這門課教**人類放手前最後的工作**：出題、引導、驗收、監督——監督到簽名那一刻，叫負責。

- 15 講、85 個小單元、規劃總長約 820 分鐘。一個單元一個概念，就是一支影片。
- 46 個現場實作，不另外開一區——哪個概念需要跑，就跑在那個單元的影片裡。程式碼、資料與參數公開，跑壞的那幾次也留著。
- 先修：15 支大金老師公開錄影的導讀清單（連結與長度在 2026-08-04 逐支確認過）。
- **沒有作業，也沒有分數。** 現在還沒有人真的來修這門課，出一份沒人會寫的作業只是自我感覺良好。等真的有人想動手，我再回來設計。
- 全部免費，沒有報名也沒有名額。

完整內容見網站或 `content.json`。

## 這個 repo 怎麼跑

```bash
node build.mjs      # content.json → docs/index.html
```

- `content.json` — 唯一內容真相源。`prereq`＝先修導讀清單；`lectures[].sections`＝小單元，每個單元可帶 `demos`（現場實作）
- `build.mjs` — 版面與渲染邏輯
- `docs/index.html` — 產出。整站單檔、零外部依賴、不追蹤、無 cookie、無廣告，可直接丟任何靜態主機

影片上線後，在該**單元**加上 `"video": {"url": "..."}`，單元列表那一行就會自動從「尚未上線」變成連結，連載進度表的分子也會跟著加一。
